Install: `npm install` · Run: `npm run dev` · Build: `npm run build` (deploy `dist` on Cloudflare Pages)
Logins: staff HK-01/HK-02/RS-01/MT-01/RC-01 · owner/demo123 · password for all: demo123
## 5-min demo
1. Launcher → Guest View (Room 305) in one window  2. Staff Login → HK-02 in another window
3. Guest: Request Service → Cleaning → watch it appear in staff  4. Guest: order food; RS-01 moves it Accept→Preparing→On the way→Delivered
5. Owner Login → Overview, Staff, Menu, Rooms & QR (generate/regenerate/print)
Tip: "Simulate guest" button creates random live requests.
